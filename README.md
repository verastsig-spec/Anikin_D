Book Tracker

**Автор:** [Данил Аникин]

Описание
Программа для ведения списка прочитанных книг. Позволяет сохранять данные о названии, авторе, жанре и объеме книги. Все данные автоматически сохраняются в файл `books.json`.

Функции
- Добавление новых книг с валидацией данных.
- Фильтрация по жанру (поиск подстроки).
- Фильтрация по количеству страниц (показ книг "от N страниц").
- Хранение данных в формате JSON.

Инструкция по запуску
1. Установите Python (версия 3.6 или выше).
2. Склонируйте репозиторий или скачайте `main.py`.
3. Запустите скрипт через терминал:
   ```bash
   python main.py
   ```

Примеры использования
1. **Добавление**: Введите "Мастер и Маргарита", "Булгаков", "Классика", "400". Нажмите "Добавить".
2. **Фильтр**: Введите "Классика" в поле жанра и нажмите "Применить".
3. **Ошибка**: Попробуйте оставить поле пустым — программа выдаст предупреждение.
